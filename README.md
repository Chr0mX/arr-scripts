# arr-scripts

A collection of automation scripts for media server management.

## Folders

- **Windows Powershell** - PowerShell scripts for Windows-based media servers
- **bash** - Bash scripts for Linux-based media servers (coming soon)

## Projects

### Trickplay Cleanup (PowerShell)

Removes orphaned trickplay metadata folders from media libraries (Jellyfin/Plex).

Location: `/Windows Powershell/`

See [Windows Powershell README](./Windows%20Powershell/README.md) for details.
